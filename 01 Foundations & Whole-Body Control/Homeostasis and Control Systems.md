# Homeostasis and Control Systems

**Function:** Keeps a variable within a context-dependent operating range despite disturbances.

**Where:** Distributed sensors, neural/endocrine integration and tissue effectors.

## Mechanism

1. A disturbance changes a regulated variable such as osmolality or arterial pressure.
2. A sensor transduces the change; its signal may represent the variable itself or a proxy, such as arterial stretch.
3. An integrating network changes effector activity, altering flows of matter or energy.
4. Negative feedback opposes the original deviation; feedforward anticipates a predictable demand.

## Control and constraints

Set points and operating ranges change with sleep, exercise and development. Positive feedback requires a terminating event, such as delivery ending cervical stretch. A steady value can conceal large balanced inflows and outflows.
