# LH

**Identity:** Luteinising hormone.

## Source

Anterior-pituitary gonadotrophs.

## Main trigger(s)

Pulsatile GnRH.

## Receptor / signalling

**Receptor:** LH/CG receptor in gonadal steroidogenic cells.  
**Canonical signalling:** Gs/cAMP/PKA.

## Main physiological effects

Ovulation/luteal function in ovaries; Leydig-cell testosterone synthesis in testes.

## Feedback / shut-off

Sex steroids feed back on hypothalamus/pituitary.
