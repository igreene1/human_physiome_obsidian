# TRH

**Identity:** Thyrotropin-releasing hormone.

## Source

Hypothalamic paraventricular neurons.

## Main trigger(s)

Low thyroid-hormone feedback and central/circadian inputs.

## Receptor / signalling

**Receptor:** TRH receptor on thyrotrophs (and lactotroph effects).  
**Canonical signalling:** Primarily Gq/PLC/IP3/Ca²⁺.

## Main physiological effects

TSH release; can stimulate prolactin.

## Feedback / shut-off

T3/T4 negative feedback.
