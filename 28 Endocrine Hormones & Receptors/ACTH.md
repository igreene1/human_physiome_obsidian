# ACTH

**Identity:** Adrenocorticotropic hormone.

## Source

Anterior-pituitary corticotrophs from POMC.

## Main trigger(s)

CRH and vasopressin.

## Receptor / signalling

**Receptor:** MC2R on adrenal zona fasciculata/reticularis cells.  
**Canonical signalling:** Gs → cAMP/PKA.

## Main physiological effects

Steroidogenesis, especially cortisol production.

## Feedback / shut-off

Cortisol negative feedback.
