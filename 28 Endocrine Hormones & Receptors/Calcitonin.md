# Calcitonin

**Identity:** Peptide hormone from thyroid parafollicular C cells.

## Source

Thyroid C cells.

## Main trigger(s)

Elevated calcium can stimulate secretion.

## Receptor / signalling

**Receptor:** Calcitonin receptor.  
**Canonical signalling:** GPCR signalling.

## Main physiological effects

Can inhibit osteoclast activity and increase renal calcium excretion; role in everyday adult calcium homeostasis is less dominant than PTH/vitamin D.

## Feedback / shut-off

Calcium-related feedback.
