# GHRH

**Identity:** Growth-hormone-releasing hormone.

## Source

Hypothalamic arcuate-region neurons.

## Main trigger(s)

Sleep, metabolic state, age and neural inputs.

## Receptor / signalling

**Receptor:** GHRH receptor on somatotrophs.  
**Canonical signalling:** Gs → cAMP/PKA.

## Main physiological effects

Growth-hormone synthesis and pulsatile release.

## Feedback / shut-off

IGF-1/GH feedback; somatostatin opposes release.
