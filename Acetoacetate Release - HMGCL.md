# Acetoacetate Release - HMGCL

**Part of:** [[Ketone Body Metabolism]]

## Transformation

HMG-CoA → acetoacetate + acetyl-CoA

| Feature | Detail |
|---|---|
| Catalyst / machinery | HMGCL |
| Compartment | Mitochondrial matrix |
| Physiological direction | Releases the first ketone body, acetoacetate |

## What controls this step

Acetoacetate may be exported, reduced to beta-hydroxybutyrate, or spontaneously decarboxylate to acetone. Oxaloacetate availability and hepatic redox state influence the overall fasting flux.
