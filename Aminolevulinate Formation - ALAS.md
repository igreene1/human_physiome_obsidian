# Aminolevulinate Formation - ALAS

**Part of:** [[Heme Synthesis and Degradation]]

## Transformation

Glycine + succinyl-CoA → 5-aminolevulinate + CO2 + CoA-SH

| Feature | Detail |
|---|---|
| Catalyst / machinery | ALAS1 or erythroid ALAS2; pyridoxal phosphate |
| Compartment | Mitochondrial matrix |
| Physiological direction | First committed heme biosynthetic reaction |

## What controls this step

Heme represses ALAS1 at several levels. ALAS2 translation is coupled to iron availability through an iron-responsive element. Vitamin B6 provides the catalytic cofactor.
