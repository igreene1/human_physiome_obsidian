# Adipose Tissue

**Role:** Stores triacylglycerol, releases fatty acids during energy deficit, secretes adipokines and contributes to thermogenesis.

## Core mechanism

fed/insulin state → glucose/fatty-acid uptake + esterification; fasting/catecholamine state → lipolysis → free fatty acid + glycerol release

## Main structures / cell types

- [[Adipocyte]]
- adipose capillaries
- immune/stromal cells
