# Sinoatrial Node

**Role:** Primary cardiac pacemaker; spontaneously depolarises and sets sinus rhythm under autonomic modulation.

## Core mechanism

diastolic depolarisation → threshold → Ca2+-dependent action potential → atrial propagation; sympathetic input accelerates and parasympathetic input slows the rate

## Main structures / cell types

- [[Pacemaker Cell]]
- HCN channels
- L-type Ca2+ channels
- β1 adrenergic receptors
- M2 muscarinic receptors
