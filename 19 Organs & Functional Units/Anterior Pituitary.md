# Anterior Pituitary

**Role:** Endocrine relay that converts hypothalamic releasing/inhibiting signals into trophic hormones controlling peripheral glands and growth.

## Core mechanism

hypothalamic factors → portal circulation → pituitary endocrine cells → ACTH/TSH/LH/FSH/GH/prolactin → target organs

## Main structures / cell types

- corticotrophs
- thyrotrophs
- gonadotrophs
- somatotrophs
- lactotrophs
