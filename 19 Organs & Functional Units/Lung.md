# Lung

**Role:** Matches ventilation with pulmonary perfusion to exchange O2 and CO2 and contributes to acid-base control.

## Core mechanism

air conduction → alveolar ventilation → diffusion across alveolar-capillary barrier → pulmonary capillary blood → systemic circulation

## Main structures / cell types

- airways
- respiratory bronchioles
- [[Alveolus]]
- pulmonary capillaries
