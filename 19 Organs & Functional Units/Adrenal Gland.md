# Adrenal Gland

**Role:** Produces steroid hormones in the cortex and catecholamines in the medulla.

## Core mechanism

cortex: ACTH/angiotensin II/K+ → steroidogenesis; medulla: sympathetic preganglionic ACh → catecholamine secretion

## Main structures / cell types

- zona glomerulosa
- zona fasciculata
- zona reticularis
