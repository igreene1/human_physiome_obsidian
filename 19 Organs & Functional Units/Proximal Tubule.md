# Proximal Tubule

**Role:** Bulk-reabsorbs filtered sodium, water, bicarbonate, glucose, amino acids and other solutes; secretes selected organic ions.

## Core mechanism

basolateral [[Na-K ATPase]] creates Na+ gradient → apical cotransport/exchange drives solute uptake → water follows osmotically → basolateral exit to interstitium/peritubular capillary

## Main structures / cell types

- [[Proximal Tubule Cell]]
- [[SGLT2]]
- Na+/H+ exchanger
- carbonic anhydrase
- aquaporins
