# Liver

**Role:** Central metabolic organ that buffers nutrients, synthesises plasma components, processes xenobiotics, produces bile and interconverts fuels.

## Core mechanism

portal + arterial inflow → sinusoidal exchange → zonated hepatocyte processing → hepatic venous outflow and bile secretion

## Main structures / cell types

- [[Hepatic Lobule]]
- [[Hepatocyte]]
- sinusoidal endothelial cells
- Kupffer cells
- bile canaliculi
