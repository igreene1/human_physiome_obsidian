# Thick Ascending Limb

**Role:** Reabsorbs Na+, K+ and Cl− while remaining relatively water-impermeable, helping create the corticomedullary osmotic gradient.

## Core mechanism

apical [[NKCC2]] + K+ recycling → basolateral Cl− exit + [[Na-K ATPase]] → net salt reabsorption without water
