# Glomerulus

**Role:** High-pressure capillary filtration unit that forms a protein-poor ultrafiltrate of plasma.

## Core mechanism

glomerular capillary hydrostatic pressure drives water/small solutes across fenestrated endothelium → basement membrane → podocyte slit diaphragm → Bowman space

## Main structures / cell types

- fenestrated endothelial cells
- glomerular basement membrane
- [[Podocyte]]
- mesangial cells
