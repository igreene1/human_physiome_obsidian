# Pancreas

**Role:** Combines exocrine digestion with endocrine control of nutrient metabolism.

## Core mechanism

acinar/ductal exocrine secretion enters duodenum; endocrine islets release hormones directly into blood

## Main structures / cell types

- acinar cells
- ductal cells
