# Hippocampus

**Role:** Medial temporal structure central to episodic/declarative memory and contextual processing.

## Inputs

Multimodal cortical information and neuromodulatory signals.

## Outputs / effects

Projects through hippocampal–cortical and limbic networks; participates in contextual regulation of stress responses.

## Core mechanism

Synaptic plasticity, including NMDA-dependent processes, supports memory formation.
