# Glutamine Synthesis - GLUL

**Part of:** [[Glutamate Glutamine Cycle]]

## Transformation

Glutamate + ammonia + ATP → glutamine + ADP + Pi

| Feature | Detail |
|---|---|
| Catalyst / machinery | GLUL (glutamine synthetase) |
| Compartment | Cytosol, including astrocytes and selected peripheral tissues |
| Physiological direction | Incorporates nitrogen into a transport/biosynthetic amino acid |

## What controls this step

Requires energy; astrocytic use supports neurotransmitter recycling and ammonia handling. Peripheral tissue roles vary, so this is not exclusively a brain reaction.
