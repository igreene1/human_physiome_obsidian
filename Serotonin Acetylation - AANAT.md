# Serotonin Acetylation - AANAT

**Part of:** [[Melatonin]]

## Transformation

Serotonin + acetyl-CoA → N-acetylserotonin + CoA-SH

| Feature | Detail |
|---|---|
| Catalyst / machinery | AANAT |
| Compartment | Pineal and selected other cells |
| Physiological direction | Provides an intermediate for melatonin production |

## What controls this step

Pineal activity is strongly controlled by circadian sympathetic signalling. This is an enzymatic step downstream of clock output, not the molecular clock itself.
