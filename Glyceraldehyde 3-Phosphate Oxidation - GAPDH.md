# Glyceraldehyde 3-Phosphate Oxidation - GAPDH

**Part of:** [[Glycolysis]]

## Transformation

Glyceraldehyde 3-phosphate + Pi + NAD+ ⇌ 1,3-bisphosphoglycerate + NADH + H+

| Feature | Detail |
|---|---|
| Catalyst / machinery | GAPDH; catalytic cysteine |
| Compartment | Cytosol |
| Physiological direction | Couples substrate oxidation to formation of an acyl-phosphate bond without directly using ATP |

## What controls this step

Requires available NAD+. Lactate dehydrogenase or mitochondrial redox shuttles regenerate cytosolic NAD+. Two molecules pass through this reaction per glucose.
