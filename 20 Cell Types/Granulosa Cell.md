# Granulosa Cell

**Location / identity:** Ovarian follicular somatic cell.

**Function:** Supports oocytes and contributes stage-dependent steroid production.

## Cellular machinery

FSH-sensitive aromatase uses theca-derived androgen precursors for estrogen synthesis. Gap-junction/paracrine support helps regulate oocyte maturation; luteinisation changes receptors and steroid output.
