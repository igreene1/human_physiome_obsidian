# Cardiomyocyte

**Role:** Contracts rhythmically to generate cardiac pressure and flow.

## Core mechanism

action potential → L-type Ca2+ entry → Ca-induced Ca2+ release from SR → troponin activation → cross-bridge cycling → relaxation via Ca2+ removal
