# Adipocyte

**Role:** Stores triacylglycerol and releases fatty acids according to hormonal/energy state.

## Core mechanism

insulin → [[Insulin Receptor]] → [[RTK PI3K AKT Signalling]] → glucose uptake/lipid storage; catecholamines → GPCR/cAMP/PKA → lipolysis
