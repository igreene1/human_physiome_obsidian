# HOW TO BUILD ANY PROCESS

Start from an actual causal question: **what changes, what detects it, and which physical or chemical event produces the response?**

1. Identify the system-level purpose and measurable quantity.
2. Name the relevant organ unit and cell type; avoid attributing every function to the whole organ.
3. Separate signalling from transport and chemical conversion.
4. For each biochemical step record substrate, product, enzyme, human gene, compartment, energy/cofactor and direction.
5. Add regulation, feedback and physiological context. A substrate requirement is different from an allosteric regulator.
6. Link to existing notes before creating duplicates, and preserve established filenames unless every link is updated.
7. Add a source that actually supports the specific mechanism; mark model-species inference and uncertainty.
8. Use [[Process Note Template]], then run the structural validator described in [[VALIDATION V4]].

Useful examples: [[Glycolysis]] for linked reactions, [[Water and Osmolality Homeostasis]] for a control loop, [[Glomerular Filtration Barrier]] for tissue architecture, and [[TCR Signalling and Costimulation]] for a branching signalling mechanism.
