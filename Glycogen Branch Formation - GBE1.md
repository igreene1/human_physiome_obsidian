# Glycogen Branch Formation - GBE1

**Part of:** [[Glycogen Metabolism]]

## Transformation

An alpha-1,4-linked glucan segment is transferred to an alpha-1,6 branch point

| Feature | Detail |
|---|---|
| Catalyst / machinery | GBE1 |
| Compartment | Cytosol at glycogen particles |
| Physiological direction | Creates branches that improve solubility and increase available ends |

## What controls this step

Requires a sufficiently long donor chain. Branch structure controls accessibility of glycogen to synthesis and degradation enzymes.
