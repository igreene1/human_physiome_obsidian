# Base Excision Repair

**Function:** Repairs many small base lesions that do not grossly distort the helix.

**Where:** Nuclear and mitochondrial DNA with compartment-specific enzymes.

## Mechanism

1. A lesion-specific DNA glycosylase removes the damaged base, creating an abasic site.
2. AP endonuclease or associated lyase activity processes the backbone.
3. Polymerase beta supports common nuclear short-patch repair; long-patch routes use additional synthesis/flap processing.
4. DNA ligase seals the repaired strand.

## Control and constraints

Different lesions use different glycosylases. BER can itself create potentially harmful intermediates if downstream steps fail. It differs from excising a whole bulky-lesion-containing oligonucleotide.
