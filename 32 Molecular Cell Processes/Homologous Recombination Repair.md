# Homologous Recombination Repair

**Function:** Repairs double-strand breaks using a homologous template.

**Where:** Nuclear DNA, especially S/G2 when a sister chromatid is available.

## Mechanism

1. MRN/CtIP and further nucleases initiate controlled end resection.
2. RPA coats single-stranded DNA, then BRCA-associated machinery supports RAD51 filament formation.
3. RAD51 promotes homology search and strand invasion into a suitable template.
4. Repair synthesis and intermediate resolution/dissolution restore DNA continuity.

## Control and constraints

Template availability and cell-cycle state influence pathway choice. HR is generally high fidelity when using an intact sister chromatid, but inappropriate recombination can rearrange genomes.
