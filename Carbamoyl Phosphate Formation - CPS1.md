# Carbamoyl Phosphate Formation - CPS1

**Part of:** [[Amino Acid Metabolism and Urea Cycle]]

## Transformation

Ammonia + bicarbonate + 2 ATP → carbamoyl phosphate + 2 ADP + Pi

| Feature | Detail |
|---|---|
| Catalyst / machinery | CPS1; obligate activator N-acetylglutamate made by NAGS |
| Compartment | Hepatic mitochondrial matrix |
| Physiological direction | Captures free nitrogen and supplies activated carbamoyl phosphate for ureagenesis |

## What controls this step

N-acetylglutamate availability links CPS1 to amino-acid load; arginine stimulates NAGS. Cytosolic CPS2 in pyrimidine synthesis uses glutamine and is a different system.
