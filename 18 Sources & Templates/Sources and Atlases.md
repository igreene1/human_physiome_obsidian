# Sources and Atlases

Use these reference resources to deepen individual notes. See [[Source Register]] for pathway and chapter references used in this edition and [[Evidence and Scope]] for sourcing limits.

## Whole Person Physiome

- https://www.wholepersonphysiome.org/
- NIH project designed to connect anatomy and healthy physiological function into a whole-body knowledge network.

## Human Reference Atlas

- https://humanatlas.io/
- Best used for **body → organ → anatomical structure → functional tissue unit → cell / biomarker** relationships.

## Reactome

- https://reactome.org/
- Curated, peer-reviewed human molecular pathway database. Best used below the cellular-process level: pathways → reactions → proteins → small molecules.

## Physiome Model Repository

- https://models.physiomeproject.org/
- Mathematical/computational models of physiological processes.

## KEGG

- https://www.kegg.jp/kegg/pathway.html
- Useful for metabolism, signalling and pathway diagrams.

## IUPHAR/BPS Guide to Pharmacology

- https://www.guidetopharmacology.org/
- Useful for receptors, ion channels, enzymes, transporters and endogenous ligands.

## Gene Ontology

- https://geneontology.org/
- Useful for standardised biological-process, molecular-function and cellular-component terms.

## How to cite additions

When you expand a process note, add a **Sources** section and link the specific database page or review used. Keep normal physiology separate from disease-specific pathways unless the purpose of the note is explicitly pathological.
