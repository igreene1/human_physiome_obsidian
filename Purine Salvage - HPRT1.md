# Purine Salvage - HPRT1

**Part of:** [[Purine Synthesis and Salvage]]

## Transformation

Hypoxanthine + PRPP → IMP + PPi; guanine + PRPP → GMP + PPi

| Feature | Detail |
|---|---|
| Catalyst / machinery | HPRT1 |
| Compartment | Cytosol |
| Physiological direction | Reuses purine bases instead of rebuilding their rings |

## What controls this step

Salvage consumes PRPP and helps regulate de novo synthesis indirectly. Adenine salvage uses APRT, a different enzyme.
