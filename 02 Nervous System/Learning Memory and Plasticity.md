# Learning Memory and Plasticity

**Function:** Changes neural circuits so experience influences later processing and behaviour.

**Where:** Synapses and distributed cortical, hippocampal, striatal and cerebellar networks.

## Mechanism

1. Coincident activity can alter postsynaptic calcium signals through NMDA and other receptors.
2. Kinases/phosphatases modify synaptic strength and receptor trafficking.
3. Longer-lasting changes recruit gene expression, protein synthesis and structural remodelling.
4. Systems-level consolidation and retrieval update representations across networks.

## Control and constraints

LTP is one mechanism, not a synonym for all learning. Different memory types depend on different circuits; reconsolidation and forgetting also involve active processes.
