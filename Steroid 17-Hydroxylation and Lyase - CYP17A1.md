# Steroid 17-Hydroxylation and Lyase - CYP17A1

**Part of:** [[Steroid Hormone Synthesis]]

## Transformation

Pregnenolone/progesterone → 17-hydroxylated forms; suitable 17-hydroxylated substrates → C19 androgen precursors by lyase activity

| Feature | Detail |
|---|---|
| Catalyst / machinery | CYP17A1; POR and context-dependent cytochrome-b5 support |
| Compartment | Endoplasmic reticulum of selected adrenal/gonadal cells |
| Physiological direction | A branching module that supplies cortisol-pathway or androgen-pathway precursors |

## What controls this step

Hydroxylase and lyase functions are distinct reactions of one enzyme. Cofactor/partner context changes their balance; cells lacking CYP17A1 cannot run the same branches.
