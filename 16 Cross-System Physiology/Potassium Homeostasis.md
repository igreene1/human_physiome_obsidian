# Potassium Homeostasis

**Regulated quantity:** Extracellular potassium concentration and total-body potassium balance.

| Control-loop element | Mechanism |
|---|---|
| Sensors / integration | Adrenal zona glomerulosa responds to extracellular K+; renal and gut-related feedforward mechanisms contribute |
| Effectors | Cellular uptake/release and distal nephron secretion/reabsorption |
| Example response | A potassium load recruits intracellular buffering and increased renal excretion |
| Time scales | Minutes for cellular redistribution; hours for substantial urinary adjustment |
| Feedback / constraint | Lower extracellular K+ reduces aldosterone and secretory drive; distal sodium delivery and flow alter effectiveness |
