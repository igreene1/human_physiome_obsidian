# Sodium Homeostasis

**Regulated quantity:** Total-body exchangeable sodium and its contribution to extracellular volume.

| Control-loop element | Mechanism |
|---|---|
| Sensors / integration | Renal perfusion/NaCl-delivery signals and cardiac/vascular filling sensors |
| Effectors | Renal tubular sodium reabsorption and sodium excretion |
| Example response | Reduced effective arterial filling recruits sodium-retaining pathways; expansion recruits natriuresis |
| Time scales | Hours-days for net sodium balance; faster signalling changes precede it |
| Feedback / constraint | Increasing effective circulation suppresses renin/aldosterone drive and supports sodium excretion |
