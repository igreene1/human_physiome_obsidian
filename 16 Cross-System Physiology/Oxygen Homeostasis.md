# Oxygen Homeostasis

**Regulated quantity:** Tissue oxygen supply relative to consumption; PaO2, saturation and content are distinct quantities.

| Control-loop element | Mechanism |
|---|---|
| Sensors / integration | Carotid bodies sense low arterial oxygen tension; HIF pathways sense cellular oxygen availability |
| Effectors | Ventilation, circulation, local flow and erythropoietic capacity |
| Example response | Acute hypoxaemia can increase ventilation; sustained renal tissue hypoxia can increase EPO and red-cell production |
| Time scales | Seconds-minutes for ventilation/flow; days-weeks for red-cell mass changes |
| Feedback / constraint | Improved delivery reduces relevant sensor stimuli; diffusion, haemoglobin and perfusion remain separate limiting steps |
