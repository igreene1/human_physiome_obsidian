# Core Temperature Homeostasis

**Regulated quantity:** Core temperature within a state-dependent functional range.

| Control-loop element | Mechanism |
|---|---|
| Sensors / integration | Peripheral thermoreceptors and central temperature-sensitive networks |
| Effectors | Skin vessels, sweat glands, skeletal muscle, thermogenic fat and behaviour |
| Example response | Heat promotes skin heat transfer/sweating; cold promotes conservation and heat production |
| Time scales | Seconds-minutes for effectors; days-weeks for acclimatisation |
| Feedback / constraint | Reduced thermal error lowers effector drive; hydration, humidity and cardiovascular capacity constrain cooling |
