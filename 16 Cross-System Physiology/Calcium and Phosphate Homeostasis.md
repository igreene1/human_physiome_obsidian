# Calcium and Phosphate Homeostasis

**Regulated quantity:** Ionised calcium, phosphate availability and mineral balance.

| Control-loop element | Mechanism |
|---|---|
| Sensors / integration | CaSR in parathyroids and other tissues; bone/kidney phosphate-related endocrine networks |
| Effectors | Kidney, intestine and bone responding to PTH, calcitriol and FGF23 |
| Example response | Low ionised calcium promotes PTH; increased phosphate-related drive can increase FGF23-mediated renal phosphate loss |
| Time scales | Minutes for hormone release; hours-days for transport/transcription and longer for remodelling |
| Feedback / constraint | Restored calcium suppresses PTH; FGF23/calcitriol feedback changes mineral transport and vitamin D metabolism |
