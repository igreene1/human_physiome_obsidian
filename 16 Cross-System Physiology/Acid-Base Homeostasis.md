# Acid-Base Homeostasis

**Regulated quantity:** Hydrogen-ion activity, with bicarbonate and CO2 as interacting components.

| Control-loop element | Mechanism |
|---|---|
| Sensors / integration | Chemosensitive networks and renal cellular acid-base sensing |
| Effectors | Buffers, lungs and renal acid excretion/bicarbonate generation |
| Example response | Nonvolatile acid consumes buffers; ventilation changes CO2 and kidneys replace bicarbonate while excreting acid |
| Time scales | Immediate buffering; minutes respiratory response; hours-days renal adaptation |
| Feedback / constraint | Compensatory processes limit pH change but do not automatically remove the primary cause; multiple primary disturbances can coexist |
