# Pentose Interconversion - RPIA and RPE

**Part of:** [[Pentose Phosphate Pathway]]

## Transformation

Ribulose 5-phosphate ⇌ ribose 5-phosphate or xylulose 5-phosphate

| Feature | Detail |
|---|---|
| Catalyst / machinery | RPIA and RPE |
| Compartment | Cytosol |
| Physiological direction | Provides ribose for nucleotides or pentoses for carbon rearrangement |

## What controls this step

Ribose demand can be met using oxidative or non-oxidative routes. The branch direction changes with the needs for NADPH, ribose, and glycolytic carbon.
