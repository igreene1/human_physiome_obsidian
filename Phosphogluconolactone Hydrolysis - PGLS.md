# Phosphogluconolactone Hydrolysis - PGLS

**Part of:** [[Pentose Phosphate Pathway]]

## Transformation

6-Phosphogluconolactone + H2O → 6-phosphogluconate

| Feature | Detail |
|---|---|
| Catalyst / machinery | PGLS |
| Compartment | Cytosol |
| Physiological direction | Hydrolyses the lactone before the second oxidative reaction |

## What controls this step

Follows substrate production by G6PD. Hydrolysis can occur spontaneously, but the enzyme accelerates controlled flux.
