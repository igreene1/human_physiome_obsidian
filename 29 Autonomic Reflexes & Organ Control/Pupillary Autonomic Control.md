# Pupillary Autonomic Control

**Role:** Opposing autonomic control of pupil diameter and lens accommodation.

## Sensor / initiating signal

Light/near-response circuits and arousal/autonomic centres.

## Integrator / pathway

Parasympathetic M3 signalling contracts sphincter pupillae/ciliary muscle; sympathetic α1 contracts radial dilator muscle.

## Effector

Gq/Ca²⁺ pathways.

## Mechanism

Parasympathetic → miosis/accommodation; sympathetic → mydriasis.
