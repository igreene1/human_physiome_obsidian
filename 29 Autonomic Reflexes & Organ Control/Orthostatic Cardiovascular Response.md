# Orthostatic Cardiovascular Response

**Role:** Integrated response preventing excessive fall in cerebral perfusion when standing.

## Sensor / initiating signal

Reduced venous return/central blood volume sensed via arterial and cardiopulmonary receptors.

## Integrator / pathway

Brainstem baroreflex networks plus hormonal responses if sustained.

## Effector

Tachycardia, increased contractility, venoconstriction and arteriolar vasoconstriction; RAAS/ADH support longer responses.

## Mechanism

Gravity → lower venous return → lower stroke volume/pressure → sympathetic activation and vagal withdrawal.
