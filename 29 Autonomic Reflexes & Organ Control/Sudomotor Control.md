# Sudomotor Control

**Role:** Autonomic control of eccrine sweating for thermoregulation.

## Sensor / initiating signal

Hypothalamic thermoregulatory output via sympathetic fibres.

## Integrator / pathway

Unusually, postganglionic sympathetic fibres release acetylcholine onto muscarinic receptors (mainly M3).

## Effector

Gq/Ca²⁺ in sweat-gland cells.

## Mechanism

Increases sweat production and evaporative heat loss.
