# Acetylcholine Synthesis - ChAT

**Part of:** [[Acetylcholine]]

## Transformation

Choline + acetyl-CoA → acetylcholine + CoA-SH

| Feature | Detail |
|---|---|
| Catalyst / machinery | CHAT (choline acetyltransferase) |
| Compartment | Cholinergic neuronal cytosol |
| Physiological direction | Combines an acetyl group with recovered or supplied choline |

## What controls this step

High-affinity choline uptake can limit synthesis during activity. VAChT subsequently packages acetylcholine using a vesicular proton gradient; synthesis and packaging are separate steps.
