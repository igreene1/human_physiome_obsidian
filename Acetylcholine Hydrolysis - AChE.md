# Acetylcholine Hydrolysis - AChE

**Part of:** [[Acetylcholine]]

## Transformation

Acetylcholine + H2O → choline + acetate

| Feature | Detail |
|---|---|
| Catalyst / machinery | ACHE |
| Compartment | Synaptic clefts and membrane-associated extracellular sites |
| Physiological direction | Rapidly terminates acetylcholine action |

## What controls this step

Recovered choline can be reused, but intact acetylcholine is not mainly cleared by a monoamine-style reuptake transporter. Butyrylcholinesterase is a related enzyme with distinct distribution.
